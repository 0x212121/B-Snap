Environment API Reference Security

Authentication

B-Snap API uses Bearer token authentication. Include the token in the Authorization header: 

Authorization: Bearer your-api-token

Base URL

http://localhost:8080/api

Endpoints

GET /api/snapshots/secure/{id}

Retrieve snapshot file by ID (authenticated)

GET /api/videos/secure/{id}

Retrieve video file by ID (authenticated)

POST /api/snapshots/gallery-view

Log gallery view for audit compliance

📖 Full API documentation available at /docs/openapi (Swagger UI)
