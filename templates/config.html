🚀 GoWA Setup Guide

1. Run GoWA with Docker:

docker run -d --name gowa -p 3000:3000 aldinokemal/go-whatsapp-web-multidevice

Or with Basic Auth (optional, recommended when exposed to the network):

docker run -d --name gowa -p 3000:3000 -e APP_BASIC_AUTH=admin:strong_password aldinokemal/go-whatsapp-web-multidevice

Then enter admin:strong_password in API Key / Auth Secret. If your older GoWA image uses AUTH_TOKEN, enter only that token.

2. Scan QR Code:

Open http://your-server:3000 and scan QR code with WhatsApp

3. Configure Webhook (Optional - for Bot):

Set webhook URL to: {{ request.base_url }}webhook/gowa

4. Save Configuration:

Enter GoWA URL, auth secret if used, and default receiver. Receiver can be a personal number or group JID. Click Test Connection, then Save.
